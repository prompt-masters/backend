# Contributing

## Branching

Always branch from `develop`:

```sh
git checkout develop
git pull
git checkout -b feature/your-feature-name
```

## Pushing

Push your branch to the remote:

```sh
git push -u origin feature/your-feature-name
```

## Pull Request

Create a pull request targeting the `develop` branch. In the PR description, describe the changes you made and any testing performed.
